# Teacher OS Starter

This is a static MVP prototype for Teacher OS.

## What it includes
- Dashboard
- Weekly Planner
- Classes
- Assessment Tracker
- Resource Library
- AI Prompt Builder
- Settings
- Local browser storage

## How to use
1. Unzip the folder.
2. Open `index.html` in a browser.
3. To publish, upload these files to a GitHub Pages repository.
