# Teacher Assistant V1.1

Static MVP prototype for a teacher planning and assistant app.

## Includes
- Dashboard with priority stack
- Weekly planner
- Task board
- Classes
- Assessment tracker
- Resource library
- AI prompt builder
- Subject/teacher modes
- Local browser storage
